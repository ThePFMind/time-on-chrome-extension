System tag rules

First match wins. Regex on the full URL (case-insensitive). Tag text: $1 = first regex group, {client} = sap-client from the URL, else the default client (SAP; leave empty for other systems), {host} = host name. Colour "Auto" reads words in the host: sbx / sandbox = Sandbox, dev / localhost = Development, test / qa / uat / staging = Test, prod / prd / live = Production. No match = the site name. Example: regex crm-(\w+)\.example\.com, tag CRM $1.
